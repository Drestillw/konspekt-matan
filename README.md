# Пределы и комплексные числа — конспект

Один файл `index.html`, без сборки. Формулы — MathJax (подгружается из CDN), картинки — canvas.

## Как выложить на GitHub Pages
1. Создайте на github.com новый публичный репозиторий, например `konspekt-matan`.
2. Нажмите **Add file → Upload files**, перетащите `index.html` (и этот README), нажмите **Commit changes**.
3. Откройте **Settings → Pages**, в разделе *Build and deployment* выберите **Deploy from a branch**, ветка `main`, папка `/ (root)`, **Save**.
4. Через 1–2 минуты сайт будет по адресу `https://ВАШ_ЛОГИН.github.io/konspekt-matan/`.
